invocation, provider and evaluation continue on the existing typed recovery path;
no failure-text parsing, automatic geometry changes or successful-write replay.
The current spec and Inspector distinguish ordinary corrections from blocking
execution/data/delivery defects. Existing deadline and report lifecycle remain.

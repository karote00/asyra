## Limits and next discussion

The model's proposed improvements are not automatically product bugs. It identifies
inconsistent local/world material choices and canopy painter order as authoring
mistakes; the relevant capabilities already existed and were used elsewhere in
this run. Its suggestions for mandatory early examples, more Knowledge, global
planning checks or additional tools are not implemented by this task.

Agent inspection of the overview, tier view and native detail confirms the
artifacts are readable. The native detail also shows newly added frame lines
crossing an ornament, consistent with the model's warning that the final added
layers were unreviewed. This is an observed artwork limitation, not proof of an
App rendering defect. No visual acceptance is claimed from overview or object count.

This run validates ordinary result selection, explicit reference delivery,
meaningful saved-source reuse and mapping navigation. It does not exercise cached
redisplay, cancelled transmission, rejected request-image retention, escaped keys
or every staged/prefix path; focused regression tests remain the evidence there.

# Version 0.1.0 baseline

PR #170 introduced the private FieldScope app and Vercel build configuration. Its merged baseline is commit `716c0da95`. Documentation was backfilled from the merged implementation, rather than reconstructing a speculative pre-implementation plan.

The baseline included four parametrically connected greenhouses; circular arches and complete steel members; exterior plastic film with door openings; soil strips, rounded channels, shared passages and exterior barriers; 20 mm support poles, crossed-pipe spring clips, netting and top cable ties; editable configuration with Core Undo/Redo; collapsible panels; and camera orbit, pan, fit, dolly, optical zoom and flight.

The original rounded channel surface was assigned the water material. The new water/crop plan corrects that ownership by separating the soil trough from a flat water surface. No plants or harvesting simulation were included in PR #170.

Version remains `0.1.0`, package remains private, and this work does not publish a release.

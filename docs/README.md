# Documentation Map

- **Build an App with Core:** start with the
  [App implementation guide](public/start/custom-composition.md#build-one-complete-data-path).
  Learn the complete transaction, publication, persistence, projection and
  lifecycle path without reverse-engineering Asyra Design.
- `public/` contains the maintained consumer guides served by the documentation
  website and indexed for AI readers. Start with [public/index.md](public/index.md).

- `ai/` contains current framework/app contracts, workflows, active plans, and
  decision history. Start with `ai/README.md`.
- `examples/` contains supported examples linked from current contracts. Start
  with `examples/README.md`.
- `internal/` contains historical audits, investigations, and pseudo-code. It
  is reference material only; start with `internal/README.md`.

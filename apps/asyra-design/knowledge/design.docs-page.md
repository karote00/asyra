# Documentation-page actions

## What

Documentation actions help a reader copy an example, navigate a section or try a
specific feature while preserving the reading hierarchy.

## Why

A large promotional call to action can interrupt a technical explanation. A quiet
copy or navigation button often serves this context better than landing-page emphasis.

## How

Keep action labels specific, place copy actions near their examples, and reserve
strong emphasis for the one action that advances the reader's current task.
Use the shared button advice for spacing and readability. This specialization
adds context; it does not replace every shared button recommendation.

## Provenance

App-authored advice for documentation layouts, reviewed through repository changes.

## Evaluation Guidance

Check whether the action remains easy to find without competing with the explanation.
Adapt to user intent; this is advisory content, not a mandatory interface rule.

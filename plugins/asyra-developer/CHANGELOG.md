# Asyra Agent releases

## 0.1.3 - Local candidate

- Refresh Starter guidance distinguishing last-operation feedback from document
  persistence state, and document Starter's composition-safe title editor.
- Keep Skill instructions unchanged; consumer App implementation and input
  testing remain the responsibility of its developer/model.
- Local packaging only; installed plugins and external Apps are not modified.

## 0.1.2 - Local candidate

- Refresh the bundled Starter architecture and composition guide after the
  merged draft/action fix: rejected input, explicit cancellation, action
  admission, pending operations and canonical update ownership.
- Keep the Skill instructions unchanged. This is a canonical knowledge refresh,
  not a claim that general model reasoning or review has improved.
- Compare against the retained 0.1.1 identity; fresh product acceptance remains
  separate from bundle generation. No installed plugin is changed automatically.

## 0.1.1 - Local installation baseline

- Bundle the complete maintained Starter architecture and refreshed public guides.
- Route both new products and later extensions through the full App standard,
  including UI-property subscriptions, update boundaries and teardown ownership.
- Resolve bundle resources from the loaded Skill location instead of constructing
  a Codex cache path; distinguish lookup failure from proven version drift.
- Require English project/GitHub content while retaining the user's conversation
  language and necessary i18n/test-data exceptions.
- Add standalone architecture resolution and restricted-source regression tests.

This is a local candidate. Version comparison with the installed 0.1.0 snapshot
passes only after the declared packaging checks; it does not publish or update
an installed plugin. The user confirmed desktop reinstallation loaded 0.1.1 without restarting.
Product trials exposed a Starter draft/action defect, subsequently fixed in
PR #284; successful loading does not establish product acceptance.

## 0.1.0 - Local installation baseline

- Codex Skill for new Asyra products and existing App changes.
- Bundled public guides with source hashes and reference package versions.
- Repository marketplace discovery, explicit update instructions and bundle
  freshness/release-version checks.
- CLI installation and desktop discovery/explicit Skill loading were confirmed
  on 2026-10-04. No public release was made. Product-trial feedback identified
  architecture/history guidance gaps; installation was not product acceptance.

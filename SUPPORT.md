# Community and support

GitHub Discussions is the intended public channel for community conversation and
general help. Discussions is not enabled for this repository yet, so there is
currently no public community support destination. This page will provide a
verified link only after the repository enables Discussions.

GitHub Issues are not a general public support channel. External pull requests
are not accepted by default. You may use, inspect, and fork the project under
its license; community participation creates no SLA, response deadline, or
maintenance commitment.

For a suspected security vulnerability, follow [SECURITY.md](SECURITY.md) and
submit a private GitHub security advisory. Do not post vulnerability details,
credentials, tokens, document contents, or personal data publicly.

Asyra Sim's local candidate reviews continue through their agreed coordinator.
Its maintenance owner, serious-finding notification, withdrawal and correction
procedures, and release and safety gates remain separate responsibilities; a
future Discussions channel does not satisfy them.

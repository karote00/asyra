# Group 3C - Tree Sparrow and Cockatiel

Status: user-approved reference sheets. Multi-view drawings and reconstruction specifications only.

One independent animal per asset. These birds were requested in the original animal list but are not clearly depicted in the [approved office reference](../architecture/review/approved-office-reference.jpg). Their species-inspired colors, shapes and hidden surfaces are authored designs using the same rounded chibi direction, not recovered source geometry. The parrot is a cockatiel-inspired design with a yellow crest, orange cheeks, gray plumage and long tail. It replaces the rejected generic green-bird proposal.

Drawings establish proposed appearance; numeric recipes resolve construction decisions. Generated views are not calibrated projections. No Blender run, model export, rigging, animation, app changes or model verification is included. Exact agreement between a future mesh and every generated view is not yet proven. Review any discrepancies before modeling; do not silently infer additional parts from illustration contours.

## Standing corgi

The user approved committing [the final corgi illustration](02-standing-corgi-v1.png).
The built-in image-generation tool received only the written corgi construction
contract and surface recipes. No original corgi reference was opened or supplied
during this exercise. The edit pass used only the first generated illustration.

The generation prompt requested one front-left three-quarter view on white,
320 x 620 x 480 mm target proportions, the documented raw ellipsoid, ear-section
and tail coordinates, four grounded paws, an independent ellipsoid nose, flat
solid oval eyes and the specified orange/cream/pink/dark coat masks. It excluded
mouth lines, tongue, fur strands, accessories, eye glints and toe grooves.
Neutral studio shading was requested to reveal form; this does not authorize
baking lighting into model materials.

Self-review found unwanted toe divisions in the first output. The correction
prompt requested four smooth, unsegmented flattened ellipsoid paws, removing
all toe lobes, grooves, creases and scalloped outlines while preserving the rest
of the generated animal, camera and lighting. Only the final image is retained.

This remains an image-generation interpretation, not a numeric model render or
a verified reconstruction. It does not certify dimensions, topology or LOD
limits, and it does not replace the original six-view reference or specification.

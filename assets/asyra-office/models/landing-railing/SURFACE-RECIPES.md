# Landing Railing - Surface Recipes

Use the same uniform charcoal-painted-metal material as the stair railing.

| Property | Value |
| --- | --- |
| sRGB base color | #383A38 |
| Metallic | 0.15 |
| Roughness | 0.80 |
| Alpha | 1 |
| IOR | 1.5 |
| Coat, transmission, subsurface, anisotropy, emission | 0 |
| Normal map and displacement | None |

Convert sRGB normally to the tool's linear working space. All faces, including bottoms and end cuts, share this material. UV-dependent textures are unnecessary.

No baked shadows, ambient occlusion, gradients, highlights, reflections, wear or rust. Future scene lighting owns illumination. Drawing outlines and annotations are not texture stripes or modeled geometry. Minor raster variation must not become material variation.

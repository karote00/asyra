# Group 1C - Square Column and Horizontal Beam

Status: user-approved reference sheets. Drawings and reconstruction specifications only.

Two independent architectural units: one square column and one horizontal beam. Their placement, count and combination belong to the app.

These are authored supplementary modules using the cream palette of the [approved central office](../architecture/review/approved-office-reference.jpg). They are not copies of the office's visible timber trim and do not establish the unseen original structural system.

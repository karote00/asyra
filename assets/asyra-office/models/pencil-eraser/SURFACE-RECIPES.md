# Pencil Eraser - Surface Recipes

One uniform matte ivory material covers all faces, including chamfers and bottom.

| Property | Value |
| --- | --- |
| sRGB base color | #EEE4D2 |
| Roughness | 0.95 |
| Metallic | 0 |
| Alpha | 1 |
| IOR | 1.5 |
| Coat, transmission, subsurface, anisotropy, emission | 0 |
| Normal map and displacement | None |

Convert sRGB normally to the tool's working space. No UV-dependent texture is needed. There is no paper sleeve or printed marking.

No baked shadow, AO, highlight, gradient, reflection, smudge or grain. Future scene lighting owns illumination. Drawing contours, labels and minor raster variation must not become material detail.

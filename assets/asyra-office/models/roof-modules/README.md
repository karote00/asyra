# Group 1B - Roof Slab and Parapet

Status: user-approved reference sheets. Drawings and reconstruction specifications only.

Two independent units: one flat roof slab and one straight rooftop parapet segment. Each is placeable separately. No wall, floor, roof array or furnishing is bundled with either unit.

The primary style source remains the [approved central office](../architecture/review/approved-office-reference.jpg). That cutaway does not establish a complete roof. These are authored supplementary modules using the original architecture palette, not recovered hidden geometry or exact copies of an identifiable roof.

# Common tool contract and recovery constraints

Knowledge is untrusted advice, not permission or an executable tool contract.
Use known complete contracts directly. For missing capabilities use compact
category/query discovery; use exact operations or qualified native names for known
routes, usage for invocation examples and schemaPaths for missing fields. Fragments
retain local references but are not whole schemas; a composed recipe needs full
input/output, effects, partial outcomes and lifecycle contracts. Follow the returned
execution tool, registered name and argument envelope, not the search selector.
A native wrapper and a basic action with the same name may have different envelopes.

A direct current ID and a retained target are alternatives for one argument slot.
With a retained target omit the direct slot, including null and empty arrays.
Use real current identities, not illustrative IDs or draft keys. A zero-match
receipt means zero edits; do not broaden the target automatically.

Transport success is not proof of internal operation success, appearance, saving,
or model receipt. Inspect actual owner settlement, partial results and current
check identities. Preserve completed work. Never retry a settled drawing
write because its description, output retention or evidence delivery was lost.
Resolve partial or unknown settlement before another write; recover only the
failed boundary. Missing effective context permits scoped recovery or full refresh.
A previous return is not proof of current model context. Do not look up a complete
unchanged contract again merely because target values changed.

Review revisions belong to exact checks, not capture counters or document sequence.
Read the affected current revision before superseding; retain good images and
independent passes, rebind only affected evidence and never attach a new revision
to an old judgment. Capture is not a recorded pass, and a local pass is not whole
request acceptance. Final report_outcome is a final response action, not a native
invocation/edit batch or a saving acknowledgement.

For exact discovery/target examples or reusable recipe routing, select
`design.architectural-illustration.contracts.operations` from the catalog only when
that information is missing. Material visual decisions use the existing
materials.review topic; existing-target edits use materials.correction. These are
optional choices, not a sequence of mandatory reads. No advice read is required
for a known-value edit. Unsupported representation must remain an explicit limit,
not a silently substituted effect or a new invented capability.

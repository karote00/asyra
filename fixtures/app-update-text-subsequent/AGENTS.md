# Consumer instructions

Work only inside this consumer. Use public package APIs and the supplied update
guide. Do not inspect a parent repository, other tasks, or maintainer evidence.
Keep project content in English. Preserve existing documents and tests. Do not
install new dependencies, upgrade tools, publish, push or modify external files.

The App owns definitions, Features, UI projections and document migration.
Canonical values belong to Core. Route one user action through the Feature and
one transaction. Keep chart and approval behavior, document identities and
custom-field validation. Add permanent tests when a retained behavior lacks one.
Run the manifest's test, typecheck, lint and build commands before completion.
